# POO-AV3

Observações:
Este trabalho vale 100% da AV3.
A realização da atividade será individual.
Qualquer indício de plágio resultará em nota 0,0 (zero) para o(s) aluno(s).
A nota será atribuída com base na entrega funcional do sistema, na arguição do código e na task prática realizada durante a avaliação.
O sistema deverá executar sem erros críticos de compilação ou execução.

Descrição:
Você está participando de um processo seletivo técnico para novos estagiários de uma grande empresa de tecnologia. Nesta fase, será avaliado seu nível de implementação em Java.
Para isso, você deverá escolher uma temática de programa e desenvolver um sistema completo, contemplando os requisitos obrigatórios definidos para a AV3.

Estrutura da Avaliação:

A AV3 será dividida em duas partes:
- Avaliação Somativa: 3,0 pontos
- Avaliação Formativa: 7,0 pontos

Avaliação Somativa (3,0 pontos):
A avaliação somativa corresponde à entrega funcional do código completo.
O sistema deverá contemplar os 10 requisitos obrigatórios definidos para a atividade. Cada item não contemplado poderá gerar penalidade de 1,0 ponto na nota geral.

Além disso, durante a apresentação, o professor escolherá 3 temas para arguição técnica, considerando o código desenvolvido pelo aluno.

Avaliação Formativa (7,0 pontos):
A avaliação formativa será realizada por meio de uma task prática aplicada durante a AV3.
Dos 10 requisitos obrigatórios, o professor poderá utilizar os demais temas não escolhidos diretamente na arguição para propor uma task completa no sistema.
Essa task deverá ser passível de realização em até 30 minutos e poderá envolver correção, adaptação, expansão ou melhoria do código desenvolvido.

Requisitos do Sistema:
1. Estrutura de Classes: criar no mínimo 8 classes, incluindo classes abstratas e a classe principal.
2. Interfaces: implementar no mínimo 2 interfaces que definam comportamentos a serem implementados pelas classes.
3. Herança: utilizar herança simples e herança múltipla por meio de interfaces.
4. Polimorfismo: demonstrar o uso de polimorfismo por meio de sobrecarga e sobrescrita de métodos.
5. Manipulação de Arquivos CSV: implementar entrada e saída de dados utilizando arquivos .csv, com leitura, escrita e salvamento de informações.
6. Encapsulamento: utilizar modificadores de acesso adequados para proteger os dados das classes.
7. Métodos Get e Set: implementar métodos getters e setters para os atributos das classes.
8. Tratamento de Exceções: utilizar tratamento de exceções com try-catch.
9. Estruturas de Dados: utilizar ArrayList, HashMap, HashSet, vetores e matrizes no sistema.
10. Boas Práticas: organizar o código de forma clara, coerente, funcional e compreensível.

Temáticas Sugeridas:
- Sistema de gerenciamento de biblioteca;
- Aplicativo de controle de tarefas;
- Plataforma de vendas online;
- Sistema de cadastro de alunos e disciplinas;*
- Sistema hospitalar;
- Sistema de gerenciamento de estoque;
- Sistema bancário;
- Sistema de reservas.

Critérios de Avaliação:
O programa deverá rodar sem erros críticos. Caso o sistema não execute corretamente, o aluno poderá perder até 3,0 pontos.
Rodar significa que o programa deve possuir entrada de dados, processamento das informações e saída de dados, incluindo salvamento e leitura por arquivo .csv.
Todos os requisitos obrigatórios deverão ser utilizados de forma funcional dentro do sistema.
